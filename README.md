Hi, I'm Patrick. I'm a technology and engineering leader based in Switzerland, with 20+ years in financial services, from architecture to leading engineering organisations. On the side I build tools around plain-text accounting and, lately, fine-tuning LLMs.

## Projects

**Natural language for Beancount**
- [fava-nl2bql](https://github.com/tarioch/fava-nl2bql): Fava extension that turns plain-English questions about your ledger into BQL queries and runs them with a small tuned model.
- [bql-lora](https://github.com/tarioch/bql-lora): training data generator and dataset for fine-tuning LLMs on the Beancount Query Language, validated against the real query engine. The model is on [Ollama](https://ollama.com/tarioch/qwen2.5-coder-bql).
- [llm-finetune-skills](https://github.com/tarioch/llm-finetune-skills): the workflow behind it as reusable Claude Code skills: data checks, local LoRA training with Unsloth, and Ollama packaging, evaluation and publishing.

**Beancount and tooling**
- [beancounttools](https://github.com/tarioch/beancounttools): importers, plugins and price fetchers for Beancount, published on PyPI.
- [flux-check-hook](https://github.com/tarioch/flux-check-hook): pre-commit hook for Flux CD that validates Kubernetes HelmRelease resources with `helm lint` and `kubectl kustomize`.
